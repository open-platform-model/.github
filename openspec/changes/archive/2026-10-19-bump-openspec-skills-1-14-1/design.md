## Context

The skills were generated by OpenSpec 1.12.0 and carry no local edit. 1.14.1 rewrites all eleven generated files.

## Decisions

- Regenerate with `openspec update --force`. Compare the result with pristine 1.14.1 output built in a scratch directory; the two MUST be byte-equal.
- No pin and no gate: this repo runs no OpenSpec CLI gate. The later rewrite change adds a pinned 1.14.1 strict gate.

## Risks

- A skill file steers agents. The diff is checked for hidden Unicode and for text that widens permissions (`allowed-tools` lines stay as generated).
